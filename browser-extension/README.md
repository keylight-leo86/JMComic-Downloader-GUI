# JMComic-Downloader-GUI 标签页复制器

适用于 Chrome、Edge 以及其他 Chromium 浏览器。点击扩展图标即可收集当前窗口中的 JM 本子/章节标签页，并按行复制链接或车号。

## 安装

### Chrome

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹：`browser-extension`。
5. 在工具栏的扩展菜单中固定“JM 标签页复制器”。

### Edge

1. 打开 `edge://extensions/`。
2. 打开左侧“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本文件夹：`browser-extension`。

## 使用

1. 在同一个浏览器窗口中打开需要下载的 JM 页面。
2. 点击扩展图标。
3. 点击“复制链接”或“复制车号”。
4. 粘贴到 `JMComic-Downloader-GUI.exe` 的输入框即可。

扩展只扫描当前窗口，支持新版 `/comic/detail?id=车号`、旧版 `/album/车号`、章节 `/photo/车号` 等地址，并按“本子/章节 + 车号”自动去重。

## Edge 点击后没有结果

1. 打开 `edge://extensions/`。
2. 找到“JM 标签页复制器”，确认版本为 `1.0.2`。
3. 点击扩展卡片上的“重新加载”按钮。
4. 回到已打开 JM 页面所在的窗口，再点击工具栏里的扩展图标。

新版不再使用弹窗模块脚本，并会把标签页权限、脚本加载和剪贴板错误直接显示在弹窗中。
