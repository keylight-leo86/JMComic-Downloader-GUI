# JMComic-Downloader-GUI v1.2.0

首个独立 GUI 发行版，基于 `JMComic-Crawler-Python / jmcomic 2.7.2`。

## 普通用户下载

下载 `JMComic-Downloader-GUI-1.2.0-Windows-x64.zip`，完整解压后运行 `JMComic-Downloader-GUI.exe`。

同时下载 `JMComic-Downloader-GUI-1.2.0-Windows-x64.zip.sha256.txt` 可核对文件完整性。

## 功能

- Windows 图形化批量下载。
- 默认保存到当前 EXE 所在文件夹下的 `下载`。
- 支持车号和 JM 链接输入。
- 完整本子/单独章节模式。
- 保持原图片尺寸，无主动 JPEG 降质。
- 按章节生成并校验 PDF。
- PDF 成功后自动清理中间图片，失败时保留图片。
- Edge/Chrome 标签页批量复制扩展 1.0.2。
- 系统代理、无代理和自定义代理。
