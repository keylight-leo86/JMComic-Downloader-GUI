# JMComic-Downloader-GUI 使用说明

## 1. 解压与启动

1. 完整解压 `JMComic-Downloader-GUI-1.2.0-Windows-x64.zip`。
2. 双击 `JMComic-Downloader-GUI.exe`。
3. 不需要安装 Python。

浏览器扩展不能直接从 ZIP 中加载，因此必须先完整解压，并且加载后不要移动 `browser-extension` 文件夹。

## 2. 下载

1. 选择“本子”或“章节”。详情页通常选择“本子”。
2. 在输入框粘贴一个或多个车号/链接。
3. 选择保存位置。
4. 一般保持默认设置。
5. 点击“开始下载”。
6. 完成后点击“打开 PDF 目录”。

多个输入可用空格、逗号、分号或换行分隔。本子与章节请分批处理，因为当前模式会应用于整批输入。

示例：

```text
1455254
JM1455254
https://devapp.18comic.cc/comic/detail?id=1455254
```

## 3. 默认设置

- 客户端：移动端 API（推荐）
- 图片格式：保持原格式
- 图片并发：20
- 章节并发：4
- 代理：跟随系统
- 高级 YAML：留空

网络不稳定时，可尝试将图片并发降到 8、章节并发降到 2，或切换移动端 API/网页端 HTML。

## 4. PDF 与图片

- 不缩小图片分辨率。
- 不主动降低 JPEG 质量。
- PDF 会进行页数校验。
- 校验成功后删除对应中间图片。
- PDF 生成失败时保留图片。
- 正常完成后最终文件位于保存位置下的 `PDF` 文件夹。

## 5. 浏览器扩展

### Edge

1. 打开 `edge://extensions/`。
2. 开启开发人员模式。
3. 点击“加载解压缩的扩展”。
4. 选择包内的 `browser-extension` 文件夹。
5. 固定扩展图标。

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择 `browser-extension` 文件夹。

在同一浏览器窗口打开多个 JM 详情页，点击扩展后可按行复制链接或车号，再粘贴到 GUI 输入框。

## 6. 常见问题

### Windows 显示未知发布者

当前 EXE 未进行商业代码签名。请从项目正式 GitHub Release 下载，并使用 `SHA256SUMS.txt` 核对文件；不要关闭杀毒软件。

### 扩展没有识别到页面

确认页面与扩展位于同一个浏览器窗口，扩展版本为 1.0.2，并在扩展管理页点击“重新加载”。

### 下载反复重试

降低并发、检查代理，或在移动端 API 与网页端 HTML 之间切换。

### 设置存放位置

```text
%LOCALAPPDATA%\JMComic-Downloader-GUI\settings.json
```

删除该设置文件可恢复默认值，不会删除已下载 PDF。

## 7. 使用边界

本项目不包含任何漫画内容。请仅下载自己有权访问和保存的内容，并遵守法律、网站条款和版权要求。
